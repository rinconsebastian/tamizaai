# Tasks

**Order.** Groups 1 and 3 to 5 (api) come first, in order; group 2 (the figure's size, ui) can run at any time, since it touches only the tile, the image and printing. Groups 6 and 7 (ui) follow group 3. Group 8 is last. `add-small-sample-warnings` (and, before it, `add-chart-annotations` and the other P1 changes; `add-indicator-column-metadata` and `add-widget-context` were archived on 2026-11-04) is implemented and archived before this change starts, and this change has been rebased onto it with `/opsx:update`; code is cited by function and constant, not by line, since the lines move; that rebase applies the spec edits that design "Spec ownership" lists under "At rebase", and `openspec validate improve-stat-cards --strict` passes after it. The per-answer rule needs no rebase: this change already uses `add-small-sample-warnings`' largest per-answer sum (design D4a).

**Release.** This change ships in the same release as `add-small-sample-warnings` (design D11, decided with the user on 2026-11-04): that change is held back until this one is implemented, and neither is deployed or rolled back alone.

Every UI string goes into both `tamiza-ui/public/i18n/en.json` and `es.json` in the task that adds it (`translations.spec.ts` checks they match). Spec scenario titles are named in backticks.

**How to run the tests** (see the memory note on the development environment): the API tests run in Docker (`dotnet test` in `tamiza-api/`, integration tests with Testcontainers; filter by class while working, for example `--filter "FullyQualifiedName~IndicatorStatQueryTests"`); the UI tests with `npm test -- --watch=false` in `tamiza-ui/`, or one spec with `npx ng test --watch=false --include='src/app/<path>.spec.ts'`, with `TZ=UTC`.
