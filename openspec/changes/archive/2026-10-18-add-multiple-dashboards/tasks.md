# Tasks

**Order.** Groups 1 to 6 (api) come first, in order; each ends with its tests green. Groups 7 to 11 (ui) follow, in order; group 7 keeps the UI build and suite green from the first type change. Group 12 (docs) can follow each group, and group 13 is last.

**How to run the tests:** `dotnet test` in `tamiza-api/` (integration tests start PostgreSQL with Testcontainers; one run at a time). `npm test -- --watch=false` in `tamiza-ui/`, where the two "stops polling when the page is destroyed" tests (`project-data.spec.ts`, `project-scripts.spec.ts`) are known failures. A single UI spec: `npx ng test --watch=false --include='src/app/<path>.spec.ts'`.
